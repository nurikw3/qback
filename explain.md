# Qalam Next Token Prediction — Архитектура

## Обзор

Система предсказания следующего слова для чагатайского языка на основе n-gram модели с Kneser-Ney сглаживанием и префиксным деревом (Trie) для быстрого автодополнения.

## Компоненты

### 1. N-gram модель (`model/ngram.py`)

**N-gram** — это последовательность из n слов. Модель хранит частоты:
- **Unigram** — отдельные слова
- **Bigram** — пары слов (слово → следующее слово)
- **Trigram** — тройки слов
- **Fourgram** — четвёрки слов

**Kneser-Ney сглаживание** — метод для оценки вероятности слова с учётом:
- Частоты в текущем контексте
- Интерполяции с моделями более низкого порядка
- Continuation probability (как часто слово появляется в новых контекстах)

### 2. Trie — префиксное дерево (`model/trie.py`)

**Задача**: быстрый поиск всех слов с заданным префиксом.

**Без Trie**: 
```
candidates = [w for w in vocab if w.startswith(prefix)]
```
Сложность: O(V × P), где V — размер вокабуляра, P — длина префикса.

**С Trie**:
```
candidates = trie.starts_with(prefix)
```
Сложность: O(P + K), где K — количество найденных слов.

**Структура**:
```
root
├── 'a' → node
│   ├── 'l' → node
│   │   └── 'm' → node (is_word=True) → "alm"
│   └── 'n' → node (is_word=True) → "an"
└── 'b' → node
    └── 'a' → node
        └── 'r' → node (is_word=True) → "bar"
```

### 3. Поток данных

```
Пользователь вводит текст
        ↓
ChagataiKeyboard.suggest_full(text)
        ↓
Парсинг: контекст + префикс (последнее слово)
        ↓
NgramModel.predict(context, prefix)
        ↓
[С Trie] trie.starts_with(prefix) → кандидаты
        ↓
Вычисление вероятностей для каждого кандидата
        ↓
Softmax нормализация → top_k результатов
```

### 4. API (`main.py`)

FastAPI сервер с эндпоинтами:
- `POST /predict` — получение предсказаний
- `GET /health` — проверка статуса

## Пример работы

**Ввод**: `"men barm"`

**Парсинг**:
- Контекст: `["men"]`
- Префикс: `"barm"`

**Поиск кандидатов через Trie**: `["barmaq", "barm", "barmek", ...]`

**Вычисление вероятностей** (bigram):
```
P("barmaq" | "men") → 0.42
P("barm" | "men") → 0.28
...
```

**Результат**:
```json
{
  "suggestions": [
    {"word": "barmaq", "score": 0.42, "source": "bigram"},
    {"word": "barmek", "score": 0.15, "source": "bigram"},
    ...
  ]
}
```

## Кэширование

- Модель кэшируется в `data/.ngram_cache.pkl` (pickle)
- Предсказания кэшируются в памяти `_cache`
- При изменении корпуса кэш перестраивается автоматически
